# 🌐 Portfólio de Templates - Venda de Sites

## 📌 Sobre o projeto

Este projeto é um **site de apresentação e venda de templates de sites**, desenvolvido para exibir modelos prontos e facilitar a captação de clientes.

A plataforma funciona como um portfólio digital, onde são apresentados diferentes layouts de sites (como barbearias, restaurantes, entre outros), permitindo que clientes visualizem exemplos antes da contratação.

---

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

---

## ✨ Funcionalidades

* 🖥️ Exibição de modelos de sites disponíveis
* 📸 Seções com preview dos templates
* 📄 Apresentação de serviços oferecidos
* 📞 Informações de contato para contratação
* 📝 Formulário de contato
* 📱 Design responsivo (adaptado para mobile, tablet e desktop)

---

## 📱 Responsividade

O layout foi desenvolvido para funcionar perfeitamente em diferentes dispositivos, garantindo uma navegação fluida e profissional.

---

## ⚠️ Aviso

Os sites apresentados são **modelos/templates demonstrativos**, desenvolvidos para fins de apresentação e comercialização, não representando empresas reais.
